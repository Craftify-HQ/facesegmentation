# facesegmentation

จัดกลุ่มภาพใบหน้าของสมาชิกในห้องด้วย K-Means (เขียนเองด้วย NumPy)

## ข้อมูล
โฟลเดอร์ `data/` เก็บภาพหน้า ตั้งชื่อไฟล์แบบ `รหัสนักศึกษา_ชื่อเล่น.jpg`

## ติดตั้ง
```bash
pip install numpy opencv-python matplotlib
```

## วิธีใช้งาน
1. ดาวน์โหลด repo นี้ (ปุ่ม Code → Download ZIP) แล้วแตกไฟล์
2. เปิด Terminal / Command Prompt ในโฟลเดอร์นี้
3. รันคำสั่ง
   ```bash
   python segmentation.py
   ```
4. โปรแกรมจะพิมพ์รายชื่อสมาชิกในแต่ละกลุ่ม และเปิดหน้าต่างแสดงภาพหน้าแยกตามกลุ่ม
5. ถ้าต้องการเปลี่ยนจำนวนกลุ่ม ให้แก้ค่า `K` บรรทัดบนสุดของไฟล์ (ค่าเริ่มต้นคือ 3)

## เพิ่มภาพหน้าของตัวเอง
นำภาพไปใส่ในโฟลเดอร์ `data/` และตั้งชื่อตามรูปแบบ `รหัสนักศึกษา_ชื่อเล่น.jpg`
แล้วรันโปรแกรมใหม่

## หลักการทำงาน
- แปลงภาพเป็นขาวดำ ย่อเป็น 100×100 แล้วแปลงเป็นเวกเตอร์
- สุ่มจุดศูนย์กลาง K จุด (seed = 0 เพื่อให้ผลเหมือนเดิมทุกครั้ง)
- จัดแต่ละภาพเข้ากลุ่มที่ใกล้ที่สุดด้วยระยะ Manhattan (L1)
- อัปเดตจุดศูนย์กลางเป็นค่าเฉลี่ยของกลุ่ม วนซ้ำจนไม่เปลี่ยน หรือครบ 100 รอบ
